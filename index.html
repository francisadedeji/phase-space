What the run does

Each of 300 runs starts from a different true state drawn from the initial spread. Every run has its own sensor noise and its own filter estimate, which starts at HP2 with the same covariance P₀. Guidance acts on the truth or on the estimate. The white cloud is where PS-1 might really be; the amber cloud is where it thinks it is.

What the run does

Each of 400 runs is a full PS-1: a relative orbit near HP2 and an attitude. The orbit law commands an acceleration in the body frame, so any attitude or mount error turns it. The attitude law is the paper’s MRP law. Volumes are measured in canonical coordinates (δr, δv, σ, p_σ).
